# Flight Management & Analytics App ✈️

A Python-based web application built with **Streamlit**, **SQL**, and **Object-Oriented Programming (OOP)** principles. This application provides an intuitive interface for viewing flight data, interacting with a local database, and visualizing trends using dynamic charts.

---

## 📁 Project Structure

```text
flights_app/
│
├── app.py              # Main Streamlit user interface and visualization logic
├── dbhelper.py         # Database helper class handling SQL connections and queries
├── venv/               # Virtual environment directory (ignored in version control)
├── .env                # Environment variables (database credentials, secrets)
├── requirements.txt    # Project dependencies
└── readme.md           # Project documentation
